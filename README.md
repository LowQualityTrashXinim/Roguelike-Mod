# Everlasting Mod

This repository is about a terraria mod. The following are detailed description of what the mod does.

Disclaimer: This mod is in a alpha state. 
It is highly recommend to not play this mod with other mod.
Multiplayer doesn't works, unless there are extremely high demand for it along with the support that we need, there won't be any plans to make multiplayer playable.

Everlasting is a mod central around sandbox roguelike, exploration, RPG elements and much more ! 
Most of what you know in terraria is not the same when playing this mod.
This is a entirely standalone mod that used Tmodloader API as a way to make it easily accessible to most player.

Introducing a lot of new systems to play around, new weapons to look for and craft into, completed vanilla items overhaul,
from just visual to new completely functionality and a lot more.

Note from the main dev :
- The mod is as the name suggest, in beta and also a demo, the mod as right now act like a boss rush, so please play the mod with open mind, cause this mod isn't like your regular terraria
